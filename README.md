# 🧮 Scientific Calculator (Python GUI)

A desktop calculator with a graphical interface built using Python and tkinter.

## 🚀 Features
- Basic arithmetic: +, -, *, /
- Power: `^`
- Square root: `√`
- Logarithm: `log`, `ln`
- Exponential: `e^`
- Constants: π and e
- Error handling

## 🛠 How to Run
Make sure you have Python 3 installed, then:

```bash
python calculator.py
```

## 🧪 Example Calculations
- `2^3` → `8`
- `√9` → `3`
- `log1000` → `3`
- `ln(e)` → `1`
- `e^2` → `7.389`
- `π * 2` → `6.28`
